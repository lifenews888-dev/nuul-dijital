# Parliament News — хувилбар 2 (site-v2)

Огноо: 2026-11-25 · Нээлтийн хугацаа: 2027-01-01

Энэ хавтсанд Claude дээр бүтээсэн сайтын хамгийн сүүлийн хувилбар байна.
Сайт одоогоор **parlamentnews.mn домэйнд байршаагүй (deploy хийгдээгүй)**. Зөвхөн Claude-ийн хувийн artifact болж ажиллаж байна. Тэр artifact-ыг зөвхөн эзэмшигч нь харна.

## Файлууд
- `index.html` — нийтийн сайт: номын тавиур, мэдээний урсгал, нийтлэл, хайлт, стори, хөл хэсэг
- `admin.html` — редакцын систем (CMS): эрх, ноорог → хянах → батлах → нийтлэх урсгал, тохиргоо
- `logo.png`, `logo-white.png`, `thumb.jpg` (хуваалцах зураг), `img/` (далбаа, ордон), `media/` (жишээ видео)
- `city.svg`, `flag.svg` — одоо ашиглагдахгүй, лавлагаа болж үлдсэн

## Бэлэн болсон зүйлс
**Нийтийн сайт**
- 3D номын тавиур (мэдээ бүр нэг ном), өдөр/шөнийн горим, утас/таблет/компьютерт тохирсон
- Мэдээний урсгал: онцлох, шинэ мэдээ, ангиллын шүүлтүүр, «Өнөөдөр парламентад» (сануулах товчтой)
- Нийтлэл: зураг/видео галерей, хуулийн төслийн 5 шатны явц, санал хураалт, шошго, хуваалцах, үсгийн хэмжээ, санал болгох мэдээ, сэтгэгдэл
- «ШУУД» ба «ЯАРАЛТАЙ» улаан мөр, гүйдэг мөрийн зар, баннер сурталчилгаа, цаг агаар, ханш
- Хайлт: ангилал, хугацаа, шошгоор; утасны доод цэс (Нүүр · Шууд · Видео · Хууль · Хайлт)

**Редакцын систем (admin.html)**
- 10 эрх: супер админ, ерөнхий редактор, хянагч, сурвалжлагч, медиа, хууль, сошиал, шууд, гадны зохиогч, шинжээч
- Бичих студи: дуугаар бичих, AI засвар, автомат засагч, формат, нүүр хавтасны дизайнер
- Зураг/видео/хавсралт байршуулах, эх сурвалж, онцлох/стори тэмдэглэх
- Тохиргоо: ирц, хөтөлбөр, цаг агаар, ханш, зар, баннер, шууд дамжуулалт, яаралтай мэдээ, хөл хэсэг, логоны байрлал

## Яагаад одоохондоо domain дээр тавьж болохгүй вэ
Сайт Claude-ийн artifact платформын үйлчилгээг ашиглаж байна (`window.claude.use(...)`):

| Үйлчилгээ | Хаана | Domain дээр юугаар солих |
|---|---|---|
| `db` — мэдээ, тохиргоо, эрх, сэтгэгдэл | index, admin | Өгөгдлийн сан + бодит цагийн шинэчлэлт (жишээ нь Supabase Postgres + Realtime) |
| `user` — нэвтрэлт, эрх | index, admin | Нэвтрэлт (Supabase Auth гэх мэт), 2FA редактор/админд |
| `assets` — зураг/видео байршуулах | admin | Файл хадгалах (Supabase Storage / Cloudflare R2) |
| `sample` — AI засвар | admin | Claude API (серверээр дамжуулж, түлхүүрийг нууцлах) |
| `dictation`, `tts` — дуу | admin, index | Хөтчийн Web Speech API эсвэл Монгол STT/TTS үйлчилгээ |

Иймээс `index.html`, `admin.html`-ийг серверт хуулаад нээвэл мэдээ хадгалах, нэвтрэх, байршуулах хэсгүүд ажиллахгүй. Зөвхөн жишээ өгөгдлөөр харагдана.

## Deploy хийх санал болгох зам
1. **Бүртгэл:** domain, hosting, Cloudflare-ийг захиалагчийн (Gerel News) нэр дээр нээж, хөгжүүлэгчид удирдах эрх өгөх
2. **Backend:** `db/user/assets/sample` дуудлагуудыг жижиг adapter давхаргаар (`pn-api.js`) орлуулах. Ингэвэл дизайн, кодын ихэнх хэсэг өөрчлөгдөхгүй.
3. **Hosting:** нүүр сайтыг Vercel/Cloudflare Pages-д, өгөгдлийг Supabase-д байршуулах
4. **SEO ба хуваалцах:** мэдээ бүрт тусдаа URL (`/news/<slug>`), Open Graph зураг, sitemap. Одоогийн нэг хуудасны бүтцэд эдгээр байхгүй.
5. **Сошиалд зэрэг нийтлэх:** Meta Graph API, YouTube Data API, Telegram Bot API (2-р шат)
6. **Аюулгүй байдал ба нээлт:** Cloudflare WAF, өдөр бүрийн DB нөөц хуулбар, ачааллын тест, дараа нь нээлт
