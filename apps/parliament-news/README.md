# Parliament News (parlamentnews.mn)

Парламентын мэдээний сайт ба редакцын систем (CMS).

> **Одоогийн хувилбар: `site-v2/`** (2026-11-25). Claude artifact дээр ажилладаг бүрэн загвар: 3D номын тавиур, мэдээний урсгал, CMS, эрхүүд.
> Төлөв, deploy хийх зам, шийдэх асуултууд: `site-v2/STATUS.md`.
> Доорх `prototype/` бол анхны (11-р сарын дунд үеийн) загвар, лавлагаа болж үлдэнэ.

`prototype/index.html` нь хөтөч дээр шууд нээгддэг, бүх зүйл нэг файлд багтсан загвар.
Бодит системийг үүнийг үндэслэн Claude Code-оор хөгжүүлнэ.

## Хөгжүүлэлт эхлүүлэх

Бодит Next.js апп энэ хавтсанд ажиллаж байна (1-р шат: схем, эрх, tenant тусгаарлалт).

### 1. Өгөгдлийн сан (локал)

Parliament News нь nuul.mn-ээс **тусдаа** сан хэрэглэнэ.

```bash
cd ../../packages/db-news
docker compose up -d          # Postgres 16, 127.0.0.1:5447
pnpm db:push                  # схемийг санд суулгах
ADMIN_EMAIL=you@example.mn pnpm db:seed
```

Seed нь `parlament` tenant, 8 ангилал, тохиргоо, супер админ үүсгэнэ.
`ADMIN_PASSWORD` өгөөгүй бол санамсаргүй нууц үгийг терминалд НЭГ удаа хэвлэнэ —
тэндээсээ хуулж ав, дахиж харагдахгүй.

Монорепогийн эхний `.env`-д:

```
NEWS_DATABASE_URL="postgresql://parlament:parlament_local_dev@127.0.0.1:5447/parlamentnews"
NEWS_DIRECT_URL="postgresql://parlament:parlament_local_dev@127.0.0.1:5447/parlamentnews"
```

Next нь `.env`-ийг зөвхөн аппын хавтаснаас хайдаг тул монорепогийн эхний
`.env`-ийг `next.config.js` зориуд уншина (`lib/env.test.ts` түүнийг хамгаална).

### 4. Хэмжигдэх зорилт

Монголын мэдээний сайтуудтай харьцуулсан суурь тоо ба дахин хэмжих командууд:
`docs/superpowers/specs/2026-11-26-mn-news-benchmark.md`.

**Зураг** (2026-11-26-нд локал дээр хэмжсэн, эх зураг 1028×778, 67 KB JPEG):

| Өргөн | Формат | Хэмжээ |
|---|---|---|
| 384px (утас) | AVIF | **5.5 KB** |
| 640px | AVIF | 8.3 KB |
| 828px | AVIF | 10.9 KB |
| 1080px (дэлгэц) | AVIF | 15.6 KB |
| 1080px, WebP дэмжихгүй хөтөч | JPEG | 38.9 KB |

Харьцуулалт: ikon.mn 296 KB, gogo.mn 335 KB, news.mn 466 KB — гурвуулаа JPEG,
`Accept: image/webp` гуйсан ч JPEG буцаана, `Vary: Accept` ч тавихгүй.
Бидний хариу `Vary: Accept` -тай.

Регресс гарсан эсэхийг шалгах:

```bash
curl -s -o /dev/null -w '%{content_type} %{size_download}
'   -H 'Accept: image/avif,image/webp,image/*'   'http://localhost:3001/_next/image?url=%2Fdemo%2Fflag.jpg&w=1080&q=75'
# Хүлээгдэх: image/avif, 120000 байтаас бага
```

### 6. Нүүрний бүтэц — юу хаанаас ирдэг вэ

Нүүрний хэсэг бүр өгөгдлийн сангийн тодорхой хүснэгтээс тэжээгдэнэ. Редакц
юуг хаанаас өөрчлөхийг энэ хүснэгтээр олно. Бүх уншилт `lib/home-data.ts`-ийн
`homeData()`-д НЭГ дуудлагаар явна.

| Нүүрэн дээрх хэсэг | Хүснэгт | Талбар | Хоосон үед |
|---|---|---|---|
| Гүйдэг мөр «ШУУД» | `pn_posts` + `pn_ticker_ads` | гарчиг; зар нь `text`, `url`, `active`, `order` | `tickerOn=false` эсвэл мэдээгүй бол мөр огт гарахгүй |
| Ирцийн хагас дугуй | `pn_live` | `attendance`, `sessionStatus` | мөр байхгүй бол виджет гарахгүй |
| Өнөөдөр хэлэлцэх асуудал | `pn_agenda` | `date` (УБ-ын өнөөдөр), `time`, `text`, `order` | мөргүй бол виджет гарахгүй |
| Стори зурвас (дугуй) | `pn_posts` | `story=true` БА `storyUntil` > одоо | стори байхгүй бол зурвас гарахгүй |
| Номын тавиур | `pn_posts` | сүүлийн 12 нийтлэгдсэн | мэдээгүй бол нүүр «Мэдээ хараахан алга» |
| Гарчгийн блокийн «ОНЦЛОХ» | `pn_posts` | `featured` | тэмдэг гарахгүй |
| Гарчгийн блокийн шатны тэмдэг | `pn_bills` | `stage` (0..4) | тэмдэг гарахгүй |
| Цагийн шугамын цэгүүд | `pn_posts` | `date` — өөрийн оны хувиар | — |
| «Өнөөдөр парламентад» | `pn_live` + `pn_agenda` | дээрхтэй ижил | «Өнөөдөр хуралдаан товлогдоогүй» |
| «Онцлох мэдээ» тор | `pn_posts` | `featured`, дутвал шинэ мэдээгээр | хэсэг гарахгүй |
| Ангиллын сонгогч | `pn_categories` | жагсаалтад байгаа ангиллууд | сонгогч гарахгүй |
| «Хуулийн төслийн явц» | `pn_bills` + `pn_bill_stages` | `title`, `stage` | «Одоогоор мэдээлэл алга.» |
| Хөлийн холбоо барих, суваг | `pn_settings` (`footer`) | `addr`, `phone`, `email`, `sales`, `fb`, `yt`, `ig`, `x` | блок гарахгүй |
| Толгойн цэс, уриа | `pn_settings` (`header`) + `pn_categories` | `inMenu`, `order` | анхдагч нэрс |

Шууд дамжуулалтын товч (`pn_live.liveOn`, `liveUrl`), баннер (`pn_banners`),
ханш (`pn_fx_rates`) нь схемд бэлэн ч нүүрэнд хараахан холбогдоогүй.

Демо өгөгдлийг бүхэлд нь сэргээх: `cd packages/db-news && pnpm db:seed:demo`.

## Редакцын студи (3a шат)

Нэвтрэх: **`/studio/signin`**. Нэвтэрсэн хүн `/studio/news` руу буух ба
бүх хуудас нь `studio/(desk)/layout.tsx`-ийн хаалгаар дамжина.

`middleware.ts` нь Edge дээр зөвхөн «токен байна уу» гэдгийг шалгана. Тэр
нь ХАНГАЛТГҮЙ: өгөгдлийн санд хэрэглэгч байж болох ч парламентын
редакцын гишүүн биш байж болно. Иймд бүрхүүл нь өгөгдөл уншихаас ӨМНӨ
`requireStudio()`-г дуудаж, `TenantMember` мөр (идэвхтэй) байгааг шалгана.

### Хэрэглэгч нэмэх

Нууц үг нь кодод, санд, лог-д ЦЭВЭР хэлбэрээр бичигдэхгүй. Шинэ
хэрэглэгчийн нууц үгийг скрипт өөрөө үүсгэж, ЗӨВХӨН терминалд нэг удаа
хэвлэнэ — дахин харуулах арга байхгүй.

```bash
cd packages/db-news
MEMBER_EMAIL=bold@parlamentnews.mn MEMBER_NAME="Б. Болд" MEMBER_ROLE=REPORTER pnpm db:seed:member
```

- `MEMBER_EMAIL` — заавал
- `MEMBER_ROLE` — анхдагч `SUPER`, доорх хүснэгтийн нэгэн байх ёстой
- `MEMBER_NAME` — сонголттой

Байгаа хэрэглэгч дээр дахин ажиллуулахад **нууц үг дарж бичигдэхгүй** —
зөвхөн үүрэг, нэр шинэчлэгдэнэ. Үүрэг солих нь хүнийг системээс гаргах
зүйл биш.

Гаралт нь жинхэнэ терминал биш (хоолой, файл, CI) бол скрипт нууц үг
үүсгэхээс татгалзана: эс бөгөөс «хаана ч хадгалагдаагүй» гэдэг нь үнэн
биш болно. Ийм үед `MEMBER_PASSWORD=...` өөрөө өгнө.

Редакцын сесс нь nuul.mn-ээс тусдаа: `NEWS_NEXTAUTH_SECRET` (`.env`) ба
`pn-auth.` угтвартай cookie. Production-д тэр хувьсагч тавиагүй бол апп
зориуд зогсоно — nuul.mn-ийн түлхүүрээр чимээгүй ажиллахаас хамаагүй дээр.

### Арван үүрэг

Үүрэг нь `pn_tenant_members.role`-д хадгалагдана. Эх сурвалж:
`site-v2/admin.html:841-886`, код нь `lib/permissions.ts`.

| Enum | Нэр | Юу засаж чадах (`SECTIONS`) | Юу хийж чадах |
|---|---|---|---|
| `SUPER` | Супер админ | `basic` `photos` `video` `bill` `src` `look` `pub` | Бүгд. Төлөвийг гараар солих нь ЗӨВХӨН энэ үүрэгт |
| `CHIEF` | Ерөнхий редактор | `basic` `photos` `video` `bill` `src` `look` `pub` | `submit` `approve` `return` `publish` `unpublish`, бүх мэдээг устгах |
| `REVIEWER` | Хянагч | `basic` `photos` `video` `bill` `src` `look` `pub` | `approve` `return`. **Нийтлэхгүй** |
| `REPORTER` | Сэтгүүлч | `basic` `photos` `video` `bill` `src` `look` | `submit` — зөвхөн ӨӨРИЙН ноорог, буцаасан мэдээн дээр |
| `CONTRIBUTOR` | Зочин зохиогч | `basic` `src` `look` | `submit` — зөвхөн өөрийн мэдээн дээр. Зураг, видео оруулахгүй |
| `MEDIA` | Зураг, видео редактор | `photos` `video` | Урсгалын үйлдэл байхгүй. Нийтлэгдсэн мэдээнд хүрэхгүй |
| `LEGAL` | Хуулийн мэдээний хариуцагч | `bill` `src` | Урсгалын үйлдэл байхгүй |
| `SOCIAL` | Сошиал менежер | `pub` | Урсгалын үйлдэл байхгүй |
| `LIVE` | Шууд дамжуулалтын оператор | — | Сайтын тохиргоо (ирц, хуваарь, ШУУД мөр) |
| `ANALYST` | Шинжээч | — | Зөвхөн ХАРНА |

Хэсгүүдийн нэр: `basic` үндсэн (гарчиг, биет, ангилал) · `photos` зураг ·
`video` видео · `bill` хуулийн төсөл · `src` эх сурвалж · `look` хавтасны
дизайн · `pub` нийтлэх сувгууд, сошиал текст.

### Урсгал

```
Ноорог → Хянагдаж буй → Батлагдсан → Нийтлэгдсэн
             ↑                ↓
             └──── Буцаасан ──┘
```

«Буцаасан» нь шат биш, хажуугийн сум: хянагч тайлбартай буцаахад мэдээ
сэтгүүлч рүү эргэнэ. Тайлбар нь ЗААВАЛ — тайлбаргүй буцаалт нь сэтгүүлчид
юу засахаа хэлэхгүй. Дахин илгээхэд тэр тайлбар арилна.

| Үйлдэл | Ямар төлөвөөс | Хэн | Болох төлөв |
|---|---|---|---|
| `submit` | Ноорог, Буцаасан | `REPORTER` `CONTRIBUTOR` (өөрийнх), `CHIEF` `SUPER` (бүгд) | Хянагдаж буй |
| `approve` | Хянагдаж буй | `REVIEWER` `CHIEF` `SUPER` | Батлагдсан |
| `return` | Хянагдаж буй, Батлагдсан | `REVIEWER` `CHIEF` `SUPER` | Буцаасан |
| `publish` | Нийтлэгдсэнээс бусад | `CHIEF` `SUPER` | Нийтлэгдсэн |
| `unpublish` | Нийтлэгдсэн | `CHIEF` `SUPER` | Ноорог |

Устгах: `CHIEF` `SUPER` бүгдийг; `REPORTER` `CONTRIBUTOR` нь зөвхөн
өөрийн хадгалсан ноорог, буцаасан мэдээг.

### Эрх нь ХААНА шалгагддаг

**UI-д товч нуух нь хамгаалалт биш.** tRPC-ийн procedure-ийг `fetch`-ээр
гараар дуудаж болно, тиймээс мутаци бүр `lib/permissions.ts`-ийн
шалгалтаар дамжина:

- `lib/permissions.ts` — бүх шийдвэр, цэвэр функц, тесттэй
- `server/routers/studio-news.ts` — `act`, `remove`; `canAct`/`canDelete`
  худал бол `FORBIDDEN`
- `ctx.db` нь `forTenant()` — `findUnique`, `update`, `delete` нь тэнд
  хориглогдсон тул `findFirst`, `updateMany`, `deleteMany` хэрэглэнэ.
  Ингэснээр **tenant-ийн хаалга эрхээс дээгүүр**: `SUPER` ч хөршийн
  ноорогт хүрэхгүй
- `components/studio/workflow-buttons.tsx` — зөвхөн ХАРАГДАХ хэсэг.
  Товчийг нуух нь дарж болохгүй товч үзүүлэхгүй байхын тул

Бичих үйлдэл бүр `pn_activity`-д мөр үлдээнэ: «хэн нийтэлсэн», «хэн
буцаасан» гэдэг хариулт байхгүй бол зөрчил гарахад хэн ч тайлбарлаж
чадахгүй. Жагсаалтын хуудасны хажууд «Сүүлийн үйл явдал» багана.

Нийтлэх, буулгах, устгах нь `revalidatePath("/")` ба
`revalidatePath("/news/<slug>")` дуудна — нийтийн хуудас `revalidate =
300`-тай тул үгүй бол редактор «Нийтэллээ» гэж харсан ч сайт дээр 5
минут хүртэл гарахгүй.

### 3a-д ОРООГҮЙ

Мэдээ засварлагч (`/studio/news/<id>`, `/studio/news/new`) нь **3b**
шатад. Тохиргоо, зургийн сан, сэтгэгдэл, хэрэглэгчийн удирдлага, самбар
нь **3c**-д.

Иймд дараах холбоосууд одоогоор **404 буцаана**: жагсаалтын «Засах»,
«Шинэ мэдээ», ба хажуугийн цэсний «Сайтын тохиргоо» (`/studio/settings`).
Тэдний эхний хоёр нь урсгалд саад болохгүй — төлөвийг жагсаалтын товчоор
хөдөлгөж болно. Гурав дахь нь `LIVE` үүргийн БҮХ ажил (ирц, хуваарь,
«ШУУД» мөр) тул 3c хүртэл тэр үүргээр хэрэглэгч үүсгэх нь эрт байна.

### Мэдээ засварлагч (3b шат)

`/studio/news/new` — шинэ мэдээ · `/studio/news/<id>` — засах.

Форм нь ЭРХЭЭР зурагдана: `lib/permissions.ts`-ийн `sectionsFor` нь
хэсгүүдийг шийднэ, зөвшөөрөгдөөгүйг нь ОГТ зурахгүй. Сервер нь мөн адил
шалгана (`pickEditable`) — товч нуух нь хамгаалалт биш.

**Талбарууд ба хязгаар** (`admin.html`-ээс яг хэвээр, `lib/studio-post-input.ts`-ийн
`LIMITS`-д нэг эх сурвалжаас):

| Талбар | Хязгаар | Хэсэг |
|---|---|---|
| Гарчиг | 160 | `basic` |
| Нурууны богино гарчиг | 40 | `basic` |
| Ангилал | 40 | `basic` |
| Сурвалжлагч | 60 | `basic` |
| Шошго | 300 (таслалаар, давхардлыг хасна) | `basic` |
| Товч агуулга | 300 | `basic` |
| Дэлгэрэнгүй текст | 8000 | `basic` |
| Эх сурвалж | 20 холбоос, зөвхөн `http(s)` | `src` |
| Хуулийн төслийн шат | 0–4, санал 0–1000 | `bill` |
| Нийтлэх суваг | Сайт, Facebook, YouTube, Instagram, TikTok | `pub` |
| Сторины хугацаа | 24 цаг / 3 өдөр / 7 хоног / хугацаагүй | `pub` |

Тэмдэгтийн тоолуур нь 90%-аас хойш улаан болно: хөтөч хязгаарт хүрэхэд
үсгийг чимээгүй залгихаа больдог.

**Хавтасны дизайн мастер** (`look` хэсэг): найман бэлэн загвар (жижиг
ном болж харагдана), гурван өнгө, зохиомж (`Зураг дээр` / `Бүтэн зураг` /
`Зөвхөн текст`), гарчгийн фонт, хэмжээ 80–125%, зургийн төвлөрөл,
2 өнгөөр будах, долоон хээ. Хавтсыг `lib/cover.ts` ГАНЦААРАА зурна —
засварлагчийн урьдчилан харалт нь нийтийн сайтынхтай яг нэг функц.

**Зураг, видео**: хөтчөөс Vercel Blob руу ШУУД. Зөвшөөрөгдөх төрөл —
зураг: JPEG, PNG, WebP, AVIF (8 МБ хүртэл); видео: MP4, WebM (200 МБ).
**SVG зөвшөөрөгдөхгүй**: blob нь файлыг өөрийн домэйнаас шууд
үйлчилдэг тул тэнд script ажиллах боломж нээгдэнэ. Эхний зураг нь ном
хавтас болно. `attachMedia` нь зөвхөн манай blob-ийн хаягийг хүлээнэ.

Vercel дээр `BLOB_READ_WRITE_TOKEN` шаардлагатай (nuul.mn-д аль хэдийн бий).

**Хаягийн дүрэм**: ноорогийн хаяг гарчгийг дагана; **нийтлэгдсэн мэдээний
хаяг ХЭЗЭЭ Ч хөдлөхгүй** (`lib/slug.ts`-ийн `nextSlug`). Эс бөгөөс
сошиалд тарсан, Google-д индекслэгдсэн холбоос бүр гарчиг засах болгонд
үхнэ.

**Зэрэгцээ засварлалт**: форм нь уншсан үеийн `updatedAt`-ийг буцааж
илгээнэ. Өөр хүн энэ хооронд хадгалсан бол сервер татгалзаж, хуудсыг
шинэчлэхийг хэлнэ — чимээгүй дарж бичихгүй.

**3b-д ОРООГҮЙ:**
- **Сошиал постын текст** — `NewsPost`-д тохирох багана алга. Сошиал
  нийтлэл нь дизайн бичгийн 5-р алхам (queue + Meta/YouTube/Telegram);
  тэр үед нэг nullable багана нэмнэ.
- **Загвар дуудсан туслах** — artifact-ийн «Редакцын туслах» (гарчгийн
  санал, товч агуулга, сошиал пост, засварлах/мэдээжлэх/богиносгох,
  хяналтын самбар) нь Claude artifact-ийн `sample()`-ийг дууддаг.
  Anthropic API-ийн түлхүүр, төлбөр шаардана.
- **Баялаг текст (Tiptap)** — дизайн бичигт нэрлэгдсэн ч `admin.html` нь
  энгийн `textarea`-тай ба нийтийн нийтлэлийн хуудас биетийг цэвэр
  текстээр, хоосон мөрөөр догол мөр болгон зурдаг. Tiptap руу шилжих нь
  нийтийн зурагчийг өөрчилнө — тусдаа шийдвэр.

## Загварт байгаа боломжууд
**Нүүр сайт**
- Дээд мөр (огноо, цаг агаар, ханш), лого, наалддаг ангиллын цэс, шуурхай мэдээний гүйдэг мөр
- Нүүр мэдээ + "Шинэ мэдээ" цагийн жагсаалт, Stories (бүтэн дэлгэцээр үзэх)
- Хуулийн төслийн явц (5 шат), Өнөөдрийн хуралдааны хуваарь
- Ангиллын блокууд, Парламент ТВ (видео), Байр суурь (нийтлэлч), Их уншсан, сурталчилгааны байр
- Мэдээ унших хуудас: зохиогч, лайк, хуваалцах, холбоотой мэдээ, сэтгэгдэл

**Редакцын систем**
- Эрх: Сэтгүүлч → Редактор → Ерөнхий редактор → Админ
- Урсгал: Ноорог → Хянуулахаар илгээх → Батлах/нийтлэх эсвэл Буцаах (тэмдэглэлтэй)
- Автомат: ноорог хадгалалт, товч агуулга, латин URL (slug), зураг шахах, үгийн тоо/унших хугацаа, бэлэн байдлын шалгалт
- Цаг товлох, шуурхай/нүүр мэдээ/Stories тэмдэглэх, сувгууд (Вэб, Facebook, Instagram, YouTube, TikTok, Telegram)
- Мэдэгдэл (🔔), үйлдлийн бүртгэл, хэрэглэгч нэмэх/эрх солих/хаах, автоматжуулалтын тохиргоо

## Анхаар: загварын хязгаарлалт
- Бүх өгөгдөл зөвхөн хөтчийн `localStorage`-д хадгалагдана. Сервер, өгөгдлийн сан алга.
- Нэвтрэлт жинхэнэ хамгаалалтгүй (нууц үг ил). Сошиал руу нийтлэх нь зөвхөн дүрслэл.
- Цаг агаар, ханш, мэдээ, хуулийн төсөл, хуваарь — бүгд зохиомол жишээ.

## Бодит хувилбарын санал болгох бүтэц
- **Frontend:** Next.js (App Router) + Tailwind
- **Өгөгдлийн сан:** PostgreSQL + Prisma
- **Нэвтрэлт:** Auth.js эсвэл Supabase Auth, нууц үг hash, 2FA (редактор/админд)
- **Зураг:** Cloudflare R2 (автомат хэмжээ, WebP)
- **Видео:** YouTube (embed) — өөрийн сервер дээр видео хадгалахгүй
- **Хамгаалалт:** Cloudflare Pro (WAF, DDoS), rate limit, өдөр бүр DB-ийн нөөц хуулбар өөр газар
- **Сошиал:** Meta Graph API (Facebook/Instagram), YouTube Data API, TikTok Content Posting API, Telegram Bot API — queue (жишээ нь BullMQ/cron)-оор нийтлэх
- **Бүртгэл:** домэйн, сервер, Cloudflare дансыг захиалагчийн компанийн нэр дээр нээж, хөгжүүлэгч удирдах эрхтэй байх
