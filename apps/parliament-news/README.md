# Parliament News (parlamentnews.mn)

Парламентын мэдээний сайт ба редакцын систем (CMS).

> **Одоогийн хувилбар: `site-v2/`** (2026-11-25). Claude artifact дээр ажилладаг бүрэн загвар: 3D номын тавиур, мэдээний урсгал, CMS, эрхүүд.
> Төлөв, deploy хийх зам, шийдэх асуултууд: `site-v2/STATUS.md`.
> Доорх `prototype/` бол анхны (11-р сарын дунд үеийн) загвар, лавлагаа болж үлдэнэ.

`prototype/index.html` нь хөтөч дээр шууд нээгддэг, бүх зүйл нэг файлд багтсан загвар.
Бодит системийг үүнийг үндэслэн Claude Code-оор хөгжүүлнэ.

## Загварт байгаа боломжууд
**Нүүр сайт**
- Дээд мөр (огноо, цаг агаар, ханш), лого, наалддаг ангиллын цэс, шуурхай мэдээний гүйдэг мөр
- Нүүр мэдээ + "Шинэ мэдээ" цагийн жагсаалт, Stories (бүтэн дэлгэцээр үзэх)
- Хуулийн төслийн явц (5 шат), Өнөөдрийн хуралдааны хуваарь
- Ангиллын блокууд, Парламент ТВ (видео), Байр суурь (нийтлэлч), Их уншсан, сурталчилгааны байр
- Мэдээ унших хуудас: зохиогч, лайк, хуваалцах, холбоотой мэдээ, сэтгэгдэл

**Редакцын систем**
- Эрх: Сэтгүүлч → Редактор → Ерөнхий редактор → Админ
- Урсгал: Ноорог → Хянуулахаар илгээх → Батлах/нийтлэх эсвэл Буцаах (тэмдэглэлтэй)
- Автомат: ноорог хадгалалт, товч агуулга, латин URL (slug), зураг шахах, үгийн тоо/унших хугацаа, бэлэн байдлын шалгалт
- Цаг товлох, шуурхай/нүүр мэдээ/Stories тэмдэглэх, сувгууд (Вэб, Facebook, Instagram, YouTube, TikTok, Telegram)
- Мэдэгдэл (🔔), үйлдлийн бүртгэл, хэрэглэгч нэмэх/эрх солих/хаах, автоматжуулалтын тохиргоо

## Анхаар: загварын хязгаарлалт
- Бүх өгөгдөл зөвхөн хөтчийн `localStorage`-д хадгалагдана. Сервер, өгөгдлийн сан алга.
- Нэвтрэлт жинхэнэ хамгаалалтгүй (нууц үг ил). Сошиал руу нийтлэх нь зөвхөн дүрслэл.
- Цаг агаар, ханш, мэдээ, хуулийн төсөл, хуваарь — бүгд зохиомол жишээ.

## Бодит хувилбарын санал болгох бүтэц
- **Frontend:** Next.js (App Router) + Tailwind
- **Өгөгдлийн сан:** PostgreSQL + Prisma
- **Нэвтрэлт:** Auth.js эсвэл Supabase Auth, нууц үг hash, 2FA (редактор/админд)
- **Зураг:** Cloudflare R2 (автомат хэмжээ, WebP)
- **Видео:** YouTube (embed) — өөрийн сервер дээр видео хадгалахгүй
- **Хамгаалалт:** Cloudflare Pro (WAF, DDoS), rate limit, өдөр бүр DB-ийн нөөц хуулбар өөр газар
- **Сошиал:** Meta Graph API (Facebook/Instagram), YouTube Data API, TikTok Content Posting API, Telegram Bot API — queue (жишээ нь BullMQ/cron)-оор нийтлэх
- **Бүртгэл:** домэйн, сервер, Cloudflare дансыг захиалагчийн компанийн нэр дээр нээж, хөгжүүлэгч удирдах эрхтэй байх

## Өгөгдлийн үндсэн хүснэгтүүд (санал)
`users` (role: journalist/editor/chief/admin) · `posts` (status: draft/review/returned/published, scheduled_at, slug, flags) ·
`categories` · `media` · `comments` · `post_channels` (суваг бүрийн нийтлэлийн төлөв) · `bills` (хуулийн төсөл, шат) ·
`sessions_agenda` (хуралдааны хуваарь) · `activity_log` · `notifications` · `settings`

## Монорепо дахь байршил
Энэ төсөл `nuul dijital` монорепогийн `apps/parliament-news` хавтсанд байрлана. Бодит Next.js апп-ыг энэ хавтсанд (`package.json`-тэй) үүсгэж, `packages/ui`, `packages/db`, `packages/config`-ийг дахин ашиглана. Загвар нь `prototype/` дотор лавлагаа болж үлдэнэ.
